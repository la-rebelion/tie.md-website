# tie.md documentation

tie.md is a local-first visual control plane for [OpenSpec](https://github.com/Fission-AI/OpenSpec) projects. It is designed to make specifications, changes, assignments, agent runs, validation, and requirements evidence easier to inspect without replacing the files or tools that already own that work.

> **Current status:** tie.md is in active MVP development. The documentation describes the intended MVP contract; installable releases will be announced in the [application repository](https://github.com/la-rebelion/tie.md).

## The short version

- **OpenSpec remains authoritative.** Lifecycle state comes from its artifacts, commands, and validation.
- **Files remain the system of record.** Markdown, YAML, Git, and project files outlive the UI.
- **Agent work is supervised.** Mutating runs expose the effective agent, skills, instructions, command, output, and changed files.
- **Traceability requires evidence.** Built, tested, passed, and delivered remain separate states.
- **Local means local.** The MVP targets loopback serving, offline project work, and no required tie.md account.
